# Locales (i18n)

## Per-project mode

The mode is decided per project; do not apply one project's mode to another.

| Project | Mode |
|---|---|
| `livarava-community` | Single locale: English only |
| Others | Keep their current setup unless the user decides otherwise |

Add new projects to this table when the user decides their mode.

## Single-locale mode (English only)

- No `i18n` block in `next.config.js`; no `locales/uk/` directory.
- No `/en/` or `/uk/` prefix in the project's own paths and links.
- Pages use `const t = en` (import only `en` from `locales/en/en`); do not import `uk` or read `router.locale`.
- Links to other projects on the same host keep their own paths as-is (some still contain `/en/`) until the user decides to change them.

## Multi-locale mode

- Keep `i18n` in `next.config.js` and both `locales/en` and `locales/uk`.
- Choose texts with `router.locale === 'en' ? en : uk`.

## Changing a project's mode

- Ask the user first; update the table above.
- After editing `next.config.js`, restart the dev server and remove `.next`.
- Check the paths (`Link`, `<a href>`), redirects and `auth` pages for the locale prefix.
